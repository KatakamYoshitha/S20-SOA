# CORS REST API

This project demonstrates a Spring Boot REST API with CORS configuration.

## API

GET `/profile`

Response:

```json
{
  "message": "Profile API is working!"
}
````

## Frontend

Frontend is created using HTML and JavaScript.

CORS allows the frontend to access the backend API from a different origin.

## Technologies

* Java
* Spring Boot
* HTML
* JavaScript
* Maven
